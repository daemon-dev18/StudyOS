# 🧠 StudyOS

A productivity dashboard built for students to manage learning, tasks, notes, planning and focus sessions in one place.

## ✨ Features

- 📊 Productivity Dashboard
- ✅ Task Management
- 🎯 Priority Based Tasks
- 📚 Subject Organization
- 📅 Daily Planner
- 📝 Personal Notes
- 🍅 Pomodoro Focus Timer
- 📈 Analytics Dashboard
- 🌙 Dark / Light Theme

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- CSS
- React Router
- Local Storage
